# AI 资产目录

在一张本机看板里搜索 Codex 和 Claude 的记忆、Skill 和 MCP。可以按名称、用途、文件位置和客户端查找，查看来源、最近文件更新时间，按需展开记忆或 Skill 的原文。

## 在 Mac 上打开

需要 Python 3.11 或更高版本。下载或克隆本仓库后，双击 `打开看板.command`。它会启动本机服务并打开浏览器，服务运行期间可收藏并访问 `http://127.0.0.1:17832/`。关闭服务终端后，再次双击即可恢复。

也可以从仓库目录运行命令。以下命令中的 `python3` 应指向符合要求的版本。

```sh
python3 server.py --open
```

打开页面、切回标签页或点击「刷新目录」都会重新扫描。页面可见时，每分钟刷新一次。左侧可切换工作方法、记忆地图与工具连接。输入用途关键词后，各分类会显示匹配数量。选择「两端共用」可筛选同时在两个客户端来源中发现的条目。

记忆地图按标题、文件名、简介和记忆类型在本机归类。主题数字表示匹配条数，点击主题可浏览条目、展开原文；点击中心可查看全部。连线表示主题归属。

如需自定义卡片的中文名称和用途，可在仓库根目录创建本机专用的 `.local-labels.json`。例如 `{"mcp:example-calendar": ["连接日历", "查询日程与会议时间。"]}`。配置会在刷新时读取，Git 默认忽略此文件。尚未设置说明的工作方法沿用来源文案。

## 数据来源

| 类别 | 读取范围 |
| --- | --- |
| 记忆 | Codex 手写记忆目录、两代自动记忆的摘要与补充笔记、Claude 项目记忆，以及已发现项目和全局的协作规则 |
| Skill | 两端用户和项目目录、Codex 系统目录、Claude 安装清单中的插件、Codex 插件的最新本地缓存目录 |
| MCP | Codex 用户及项目 TOML、Claude 用户及项目配置、项目的 MCP 文件和插件声明 |

项目来自客户端配置中记录且仍在本机的路径。其他项目可以通过一个或多个 `--project /path/to/project` 参数纳入。工具读取约定位置，适用于具备相应本地文件的安装方式。纯远程动态注册的工具可能不会出现在目录里。

记忆和 Skill 按正文内容合并，同名但正文有差异的条目保留各自的来源。MCP 按服务名分组，可在详情中查看每处配置状态。插件缓存、安装、配置启用分别标记。是否已连接、鉴权是否有效，需要在对应客户端确认。文件更新按本机文件修改时间排序。

## 本机数据与示例

服务只监听 IPv4 回环地址。真实清单在扫描时生成，保存在内存中。MCP 详情只显示名称、配置所在位置和声明状态。页面资源随程序提供，无外部字体、统计脚本或云端接口。

使用虚构数据预览界面：

```sh
python3 server.py --demo --port 17833 --open
```

代码仅依赖 Python 标准库。前端由原生 HTML、CSS 和 JavaScript 构成。
